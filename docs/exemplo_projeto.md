# Notas do projeto Aurora

O projeto Aurora é um sistema de irrigação automática para hortas urbanas, criado em 2025.
Ele usa um microcontrolador ESP32 e sensores de umidade do solo. A rega é acionada quando a umidade cai abaixo de 30%.
O orçamento total do protótipo foi de R$ 480, e a equipe tem três pessoas.
